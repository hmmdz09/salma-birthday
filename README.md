# Happy Birthday Salma Aulia ✨🎂

A modern, interactive, and aesthetic birthday website created with love and care for **Salma Aulia**.

## ✨ Features
- **Curtain Welcome Screen**: Elegant entrance with portrait glow, celebration music, and confetti bursts.
- **Vinyl Music Player**: Realistic spinning vinyl record playing custom celebration background music.
- **Interactive Birthday Cake & Candles**: Blow out candles with real-time smoke physics, chime arpeggios, and multi-burst fireworks confetti.
- **3D Interactive Envelope**: Wax-sealed letter that opens with a 3D animation revealing a heartfelt birthday message.
- **Polaroid Memory Gallery**: 3D tilt interaction on hover, fullscreen lightbox viewer, and dynamic local photo adder.
- **7 Sweet Reasons**: Glassmorphism cards appreciating Salma's beauty, kindness, and wonderful personality.
- **Interactive Wishes Board**: Permanent local-storage-backed board where friends can leave sweet birthday wishes.
- **Love & Appreciation Meter**: Heart burst animations and milestone celebratory fireworks.

## 🛠️ Tech Stack
- **HTML5 & Vanilla CSS3**: Glassmorphism, 3D Transforms, Responsive Layout, Keyframe Animations.
- **JavaScript (ES6+)**: Web Audio API Sound Synthesis, Canvas Confetti, Starfield Ambient Canvas, LocalStorage.
- **Assets**: Optimized WebP imagery & audio.
